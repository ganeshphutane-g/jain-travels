1. Introduction

Jain Travels is a responsive travel booking website designed to help users explore destinations, view travel packages, book trips, and learn about company services. The project demonstrates proficiency in HTML5, CSS3, and JavaScript through a fully functional static website deployed on GitHub Pages.

The website provides an intuitive user interface with navigation, hero banner, booking form, package gallery, services section, photo gallery, about us section, footer, and user authentication (login and register pages).

2. Objectives

  • Design a professional travel agency website with modern UI
  • Implement interactive features using JavaScript (country rotation, form validation)
  • Create user registration and login with client-side validation
  • Deploy the website on GitHub Pages for public access

4. Page-wise Description

4.1 Home Page (index.html)

  • Navigation Bar: Brand logo and name (Jain Travels), menu links (Home, Book, Packages with dropdown, Services, Gallery, About), Login and Register buttons
  • Hero Section: Full-width background image (90vh), welcome heading, rotating country names every 0.2 seconds, Book Now button
  • Booking Section: 50/50 layout — brand image and booking form (Where to, Persons, Start/End dates, Description 50–500 chars)
  • Package Gallery: 9 destination cards in 3×3 grid with image, name, attractions, USD price, rating, Book Now
  • Services: 6 service cards (Affordable Hotel, Food & Drinks, Safety Guide, Airport Transfer, 24/7 Support, Custom Itinerary)
  • Travel Gallery: 12 photos with CSS transform: scale(1.1) on hover
  • About Us: 50/50 layout with team image and company information (Established 2010)
  • Footer: Brand name, social media icons (Facebook, Instagram, Twitter, LinkedIn), copyright

4.2 Register Page (register.html)

Registration form with fields: Full Name, Contact, Date of Birth, Email ID, Password, Gender (Male/Female/Other), and Register button. Link below redirects to login page. JavaScript validates all fields before saving user to localStorage.

4.3 Login Page (login.html)

Login form with Email ID and Password fields. Link below redirects to register page. Validates credentials against localStorage and redirects to home on success.

5. Key Features Implemented

  • Packages dropdown menu on hover (United State, India, France, Germany)
  • Automatic country name rotation in hero section
  • Booking form validation with date and description rules
  • Gallery image hover scale effect
  • Responsive layout for tablet and mobile
  • Register validation: name, 10-digit contact, age 18+, email format, password strength, gender selection
  • Login validation with success/failure messages
  • Pre-seeded evaluator account for grading
